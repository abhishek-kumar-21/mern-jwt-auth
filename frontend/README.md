# Frontend - MERN JWT Auth

This is the React frontend for the authentication system. It features modern routing with `react-router-dom` and is styled with Tailwind CSS and shadcn/ui components.

## Setup Instructions

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm start
   ```

3. **View the app:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.

*Note: Make sure your backend server is simultaneously running on port 3001 so the frontend can successfully make API requests.*
